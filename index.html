Sierro Energy PWA

Source + PWA config are on main. Full dist/ deploy is blocked until GitHub Actions workflow scope is granted (or you publish dist manually).

  1. Push .github/workflows/pages.yml from the local project (token needs workflow scope).
  2. Repo → Settings → Pages → Source: GitHub Actions.
  3. Private repos need GitHub Pro for Pages, or make the repo public.

Local preview: npm run build && npx vite preview
